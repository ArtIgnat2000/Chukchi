# Чукчи — люди настоящей тундры

Интерактивная школьная презентация на пять выступающих.

- `index.html` — основная презентация;
- `speaker.html` — печатная шпаргалка с пятью текстами;
- `style.css` и `script.js` — оформление и интерактивы.

Откройте `index.html` в браузере. Для публикации подходит GitHub Pages без сборки.
